# 用于NEXUS电嵌电机学习

本仿真数据来自实验室练习电机，不同电机参数不一致，需要灵活调整，切不可照本宣科。

单屏、纯浏览器仿真的中文 PID 教学工具，可直接打开 `index.html` 离线使用。

- 六课实验：比例、积分、负载、PWM 上限、抗积分饱和、微分。
- 双电机动画、实时速度与 PWM、播放中加/撤负载。
- 参数调整自动重播；速度/PWM/PID 曲线及修改前后对照。
- 0.3×、0.5×、0.8×、1×、2×、4× 播放速度。
- 自主练习：固定双轮 600 cps / 30% PWM，5秒加载、10秒撤载，独立调 PID 后提交评分。
- 评估包含双轮波形、五项指标、四步调参引导、分段诊断和可下载 HTML 报告；所有作答仅在浏览器本地计算。
- 评估波形用红/黄/紫/粉分别标记超调、末段偏差、响应慢、PWM到顶；附阈值图例及时间区间。
- CSV、PNG 导出；无串口或实机控制功能。

## 模型与边界

一阶惯性和等效运动死区模型，含编码器量化与测速低通。它是教学近似，不复现完整起转摩擦、温升或方向不对称，也不能替代实机验收。
速度单位 cps 为编码器计数/秒。动画统一采用 600 cps = 1 圈/秒的展示比例，不能按动画推算真实轴转速。模拟参数摘要见 `model_fit.json`。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/ (root)`。无需构建或第三方依赖。
